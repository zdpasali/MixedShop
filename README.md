# MixedShop – ASP.NET Core Web Shop

Web application for selling products across multiple categories built with ASP.NET Core MVC.

MixedShop is a simple e-commerce web application that allows users to browse products, register/login, and place orders. The system uses Entity Framework for database interaction and SQL Server for data storage.

## Features

- Product listing with category filtering
- Featured items displayed on the homepage
- User registration and login
- Session-based shopping cart
- Order placement restricted to authenticated users
- Database integration using Entity Framework

## How It Works

Users can browse all items or filter products by category.  
Products added to the cart are stored using session functionality, allowing users to continue browsing without losing selected items.

Authentication is required before completing an order.

## Tech Stack

- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML / CSS

## Purpose

This project was developed as part of university coursework to demonstrate web application development using ASP.NET Core, database integration, authentication, and session management.
